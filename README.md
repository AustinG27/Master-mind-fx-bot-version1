# Master-Mind FX — XAUUSD Scalper

Live gold scalping scanner: 4H/1H structure and trend, support and resistance zones, 5m/15m candlestick confirmation, three take-profits, XM MT5 order tickets and a self-learning AI.

Open the live site: `https://YOUR-USERNAME.github.io/mmfx-scalper/`

## Publish it (no coding needed)

1. Sign in at github.com and click **New repository**. Name it `mmfx-scalper`, choose **Public**, and click **Create repository**.
2. Click **uploading an existing file**, drag in `index.html` and this `README.md`, then click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then click **Save**.
4. Wait a minute or two and refresh the Pages screen. Your link appears at the top: `https://YOUR-USERNAME.github.io/mmfx-scalper/`

**To update later:** open the repository, click **Add file → Upload files**, drag in the new `index.html` and commit. The site updates within a couple of minutes.

## First time you open the link

1. **Settings → Match XM Global prices:** type the GOLD Bid from XM MT5, press Match, set your spread, and save.
2. **AI learning → Learn from history → Last 90 days.**
3. Click **Turn on alerts** each time you open the page, so sound and notifications can play.

## Good to know

- **Everything is saved in each visitor's own browser:** settings, signal history and the AI brain. Every member who opens the link starts fresh, so share a trained brain with **Export brain** and **Import brain**.
- **API keys never go into the repository.** A Twelve Data key typed into Settings stays in that browser only. Don't paste keys into any file you upload, because public repositories can be read by anyone.
- **The page has to stay open** to catch signals and keep learning. The 24/7 server version with Telegram posts can come later.
- **Price data comes from Binance.** In the few countries where Binance is blocked, the page can't load prices.
